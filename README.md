# 🌐 UltraEdit Website Clone

A responsive clone of the UltraEdit website, built from scratch using **raw HTML and CSS** (no frameworks), to practice front-end layout and design.


## ✨ What I Practiced

- Page structure with semantic HTML
- Styling and layout with CSS (Flexbox)
- Working with images and assets (WebP, PNG)

## 🛠️ Tech Stack

HTML5, CSS3

## 🚀 How to Run

1. Clone the repo:
   ```bash
   git clone https://github.com/itsSana-Noor/Ultra-Edit-Website-clone.git
   ```
2. Open `index.html` in your browser.
